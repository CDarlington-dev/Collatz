3x+1 Class records calculation progress map
Status of the 3x+1 class record progress as of: Jul 29, 2026.
Intervals are indicated in units of 1,000,000,000,000 (1 E+12 or 1 trillion numbers).
Calculation of a single block of 10,000 units takes approximately 2-4 days on an NVIDIA graphics processor.

All class records found so far can be viewed on the class records page.
This project can only run because of many cooperating contributors.
If you would like to contribute one or more blocks please go to the search page.
Note: the 3x+1 problem is just one of many distributed projects on the internet.
