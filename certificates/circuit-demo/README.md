# Circuit/LRAT demonstration certificate

These two files refute the 206-clause formula generated by
`Collatz.Certified.Circuit.Demo.interval26to27OneStepBad`.  That circuit performs one genuine
8-bit accelerated Collatz step on the two inputs 26 and 27 and asserts that the successor's low
bit is zero.  The actual successors are 13 and 41, so the assertion is impossible.

This is a small end-to-end check of the certificate format and Lean reconstruction path.  It
does **not** prove or contribute coverage for
`FiniteBaseClassification 1000000000 PublishedClassification` (FB-1), and it does not justify
any target-scale exclusion theorem.
